# SkyRoute

**飛行機が「どこを、どの高さで、どのような天候の中を飛ぶのか」を、3D地図で見られるWebアプリです。**

便を選ぶと、航空機の位置や飛んできた道筋、目的地までの経路を立体的に表示します。空港周辺の雨・雷なども重ねて確認でき、AIが飛行状況を日本語で説明します。

Googleの写実的な3D地図、航空機モデル、運航データ、航空気象情報を組み合わせた個人開発プロジェクトです。PCとスマートフォンに対応しています。

## まず使ってみる

1. **起動すると羽田空港付近に飛行機が表示されます。** この機体は操作確認用で、選択した実便の現在位置ではありません。
2. **実際の便を見るなら「LIVE」へ。** 便一覧で空港を選び、パネル右上の「更新」を押します。飛行中の出発便と、今後3時間の出発予定便を取得します。
3. **便一覧から1便を選びます。** 取得できた位置・高度・速度・経路などが表示されます。
4. **「Preview Flight」「Replay Track」で再生できます。** 前者は今後の飛行のシミュレーション、後者は過去の航跡の再生です。
5. **「AI解説」を押すと、日本語で飛行状況を説明します。** 「音声」で読み上げ、「停止」で止められます。

実便を取得せず操作を試す場合は、**DEMO**を選んでください。羽田から伊丹・新千歳・福岡・那覇へ向かう4つのサンプル便を、異なる機体で再生できます。

左上の**SkyRouteロゴ**を押すと、ページを再読み込みして初期状態に戻ります。

## LIVE・DEMOと再生の違い

| 表示・操作 | 何を見ているか |
|---|---|
| LIVE | AeroAPIから取得した実際の運航情報。位置には取得時刻があり、常に最新とは限りません。 |
| Preview Flight | 取得できた経路などを使った今後の飛行のシミュレーション。位置がある飛行中便は、便選択時の位置から目的地へ進みます。 |
| Replay Track | 取得できた過去の航跡を、便選択時の位置まで再生します。 |
| DEMO | あらかじめ用意した経路で飛ぶサンプル。機体位置・高度・速度はシミュレーションです。 |

**LIVEの飛行中便の位置は、便を選んだときに取得します。** 現在の画面では、API利用を抑えるため自動位置更新を無効にしています。位置を取り直す場合は便を選び直してください。Preview・Replayの再生操作では、現在位置APIを追加で呼びません。

DEMOでもGoogle Mapsを利用します。また、SIGMETとNOWCASTは現在の実際の気象データを取得します。すべてがオフラインのサンプルではありません。

### 選べる出発空港

羽田、成田、関西、伊丹、新千歳、福岡、那覇の7空港です。初期選択は羽田です。

## 画面の見方と操作

| パネル | 主な内容 |
|---|---|
| 便一覧 | 空港選択、便の絞り込み、便選択、右上の「更新」 |
| 飛行情報 | 便名、機種、出発・到着時刻、位置、高度、速度、AI解説など |
| カメラ | 視点、機体モデル、地図の種類、方位、回転、傾き |
| 再生バー | 再生・逆再生・先頭へ戻る・速度変更・再生位置の移動 |
| 高度・時間 | 経路に沿った高度変化のグラフ |
| ルート色 | 実測・予定・推定の経路の凡例 |
| WEATHER | 夜間表示、SIGMET、NOWCAST、雨・雷・竜巻の表示切替と説明 |

右上の**「操作」**から各パネルの表示・非表示を切り替えられます。スマートフォンではパネルを画面下側に縦に並べ、スクロールして操作します。

### カメラ

| モード | 見え方 |
|---|---|
| COCKPIT | 操縦席に近い視点 |
| CLOSE | 機体のすぐ後方から追従 |
| FOLLOW（初期設定） | 少し離れた後方斜め上から追従 |
| OVERVIEW | 航路を広く見渡す視点 |
| FREE | 地図を自由に操作する視点 |

FOLLOWは機体の位置にカメラの中心を合わせ、向きだけを経過時間に応じて滑らかに追従させます。広い航路をOVERVIEWで見るときは、位置を把握しやすいよう機体の表示サイズを調整します。

地図は、地名などを重ねる**HYBRID**と、ラベルを抑えた**SATELLITE**を切り替えられます。航空機モデルは機種・航空会社に応じて自動選択し、カメラパネルから手動でも変更できます。起動時のモデルはランダムです。

### 夜間モード

WEATHERの**「夜間：自動／ON／OFF」**で切り替えます。

| 選択 | 動作 |
|---|---|
| 自動 | 表示中の飛行時刻が日本時間18:00〜翌5:00なら夜間表示 |
| ON | 時刻に関係なく夜間表示 |
| OFF | 時刻に関係なく昼間表示 |

LIVEは位置データの時刻、Replayは航跡に沿った再生時刻、Preview・DEMOはシミュレーション上の時刻を基準にします。初期状態など飛行時刻がない場合は現在時刻を使います。

地図の上に半透明の濃紺のフィルムを重ね、通常は1.5秒かけて明暗を切り替えます。パネルの明るさは変えず、地図・機体・ルート・気象表示が一緒に暗くなります。夜景写真や街の照明を再現する機能ではありません。

## ルートと飛行情報

| 色・種類 | 意味 |
|---|---|
| 水色・ACTUAL | 実際に飛行した航跡 |
| 青・FILED | 取得できた予定経路 |
| オレンジ・ESTIMATED | 予定経路が得られない場合などにアプリが作る推定経路 |

ルート線は曲がり角と高度変化を補間して滑らかに表示します。実測航跡は取得した点を保った表示用の補間です。Preview・DEMOの旋回や空港周辺の上昇・降下には、見やすくするための模擬経路も含みます。実際の管制指示や離着陸手順を再現するものではありません。

飛行情報では、取得できた範囲で予定・推定・実績の時刻、遅延、高度、速度、方位、飛行フェーズなどを表示します。未取得の項目がある便もあります。

**目的地までの残距離は直線距離です。** 実際にこれから飛ぶ経路の長さとは異なります。残時間も距離と速度などから求める目安で、正式な到着予測ではありません。

## 天気の見方

WEATHERでは、**SIGMETとNOWCASTを別の情報として扱います。** どちらも初期設定はONで、便・航路の選択後に必要な情報を取得します。

### SIGMET：航空機に関係する重要な気象情報

乱気流、着氷、火山灰、台風などの対象空域を表示します。NOAA Aviation Weather Centerから取得し、航路からおおむね250km以内の情報を抽出します。

日本の福岡FIR（RJJJ：航空情報を担当する空域）の情報は、**気象庁が発表したものをNOAA経由で取得**しています。

| 色 | 現象 |
|---|---|
| オレンジ | 乱気流 |
| 青 | 着氷 |
| 紫 | 火山灰 |
| ピンク | 台風・熱帯低気圧 |
| 黄土色 | 山岳波 |
| 赤 | その他・雷雨など |

高度帯が取得できる場合は、下限と上限の間を立体表示します。例えばFL130〜FL210なら、単純換算で約3,962〜6,401mです。FLは気圧を基準にした高度で、描画ではフィートをメートルに換算して絶対高度として扱います。

- 下限不明・上限ありの場合は、表示上の下限を0mにします。
- 上限不明、上下が逆、または高度差30m以下の場合は、地表の平面表示にします。
- 点として配信される情報は、表示補助として半径45kmの円で示します。この円は公式の警戒範囲ではありません。
- 広域の空域では、地球の曲率や大きな面の描画により、指定高度と見た目の高さが一致しない場合があります。

SIGMETは5分間キャッシュし、表示が有効な間は定期的に再取得します。0件という表示は、飛行の安全を保証する意味ではありません。

### NOWCAST：空港周辺の雨・雷・竜巻発生確度

気象庁のナウキャストを使い、出発・到着空港の周辺を表示します。

- パネルでは、空港直上と周辺約10kmの降水強度などを確認できます。
- 3D地図では、それぞれの空港の周辺30kmを対象に、雨・雷・竜巻発生確度を表示します。
- **「雨」「雷」「竜巻」**は個別に表示・非表示にできます。
- **「NOW」「+60分」**で現在と約60分後の情報を切り替えます。情報の有無や対象時刻は配信データによります。

**NOWCASTの柱や箱の高さは、強さを見やすくするための表現です。** SIGMETの高度帯とは異なり、実際の雲・雷・竜巻の高さを示しません。竜巻発生確度も、竜巻が実際に発生したことを示す情報ではありません。

### 空港の観測と予報

AI解説などには、NOAAから取得する以下の情報も使います。

| 用語 | 意味 |
|---|---|
| METAR | 空港で観測した風・視界・雲・気温などの情報 |
| TAF | 空港周辺の今後の気象予報 |

空港の天候は、飛行中の機体のすぐ周囲の天候とは限りません。

## AI解説と音声

「AI解説」を押すと、Geminiが便情報、位置、高度、速度、経路、空港の観測・予報、SIGMET、NOWCASTをもとに解説します。

- 「現在の状況は、」から始まる自然な日本語で、**最大1,200字**にまとめます。
- 時刻は**日本時間（JST）**で説明し、予定・推定・実績を区別します。
- LIVEの残距離はアプリ側で位置と到着空港から計算し、文章内へ組み込みます。
- DEMOでは模擬飛行と実際の気象データを区別します。便選択時に表示する仮の解説もあります。

モデルの既定値は `gemini-3.5-flash-lite` です。音声はGoogle Cloud Text-to-Speechの `ja-JP-Wavenet-A` を既定値として使用します。

AIの説明には誤りが含まれる可能性があります。入力にない情報の推測や、気象情報だけから安全を断定しないよう指示していますが、正確性を保証するものではありません。

## データ取得とAPI利用

| 操作・機能 | 主な通信 |
|---|---|
| 地図を開く・動かす | Google Mapsの地図表示 |
| 便一覧の「更新」 | AeroAPIの便一覧取得 |
| 実便を選択 | 必要な便詳細・位置・航跡・予定経路などの取得 |
| Preview・Replay | 取得済みの位置・経路を使って再生。Previewでは空港の風情報を取得する場合があります。 |
| 気象表示 | NOAA・気象庁データの取得。キャッシュや定期更新を利用します。 |
| AI解説 | Gemini。解説に必要な気象情報も取得します。 |
| 音声 | Text-to-Speechによる音声生成 |
| INFO | 概要・使い方・AeroAPIの今月の利用状況の確認 |

空港の名称・座標などはローカル空港マスタを利用し、AeroAPIへの依存を減らしています。夜間表示やカメラの切替自体には、AeroAPIやGeminiの呼び出しはありません。

INFOの利用額は参考値です。提供元の集計反映に時間差があるため、最終的な請求額とは一致しない場合があります。

## 開発者向け：ローカル起動

必要なものは **Node.js 22.6以上、npm、Google Mapsのブラウザ用APIキー**です。実便の取得にはAeroAPIキー、AI解説にはGemini APIキーも必要です。

1. 依存パッケージをインストールします。

   ```sh
   npm ci
   ```

2. `.env.example` をコピーして `.env.local` を作り、必要な値を設定します。

   ```dotenv
   VITE_GOOGLE_MAPS_API_KEY=YOUR_GOOGLE_MAPS_API_KEY
   SKYROUTE_DATA_MODE=mock
   AEROAPI_KEY=YOUR_FLIGHTAWARE_AEROAPI_KEY
   AEROAPI_MAX_CALLS_PER_MINUTE=20
   GEMINI_API_KEY=YOUR_GEMINI_API_KEY
   GEMINI_MODEL=gemini-3.5-flash-lite
   PORT=8787
   ```

   `mock` は開発用の模擬APIです。実便を取得するときは `SKYROUTE_DATA_MODE=live` に変更します。画面上のDEMOモードとは別の設定です。

3. 開発サーバーを起動します。

   ```sh
   npm run dev
   ```

   ブラウザで `http://localhost:5173` を開きます。フロントエンドとバックエンド（既定ポート8787）が同時に起動します。

AeroAPI・Geminiのキーはサーバー側で扱います。`VITE_` を付けるとブラウザ向けに組み込まれるため、これらのキーには付けないでください。`.env.local` や認証情報はGitへコミットしないでください。Google Mapsのブラウザキーには、利用サイトとAPIの制限を設定してください。

現在のクラウド音声生成は、Google Cloudのメタデータサーバーから実行サービスアカウントの認証を取得します。通常のローカル環境では、そのまま利用できません。

### ビルド・テスト

```sh
npm run build
npm test
```

ビルド結果は `dist/` に出力します。`npm start` はバックエンドとビルド済み画面を配信します。

テストには、経路・再生・カメラ、夜間判定、SIGMET、NOWCAST、AI解説、API、PLATEAU関連が含まれます。一部のPLATEAUテストには生成済みのデータが必要です。関連データの生成には `npm run build:plateau`、ブラウザテストには `npm run test:browser` を使います。

### 主な構成

| 場所 | 役割 |
|---|---|
| `src/flight/` | 運航データ、飛行・再生処理、ルート補間 |
| `src/map/` | 地図、機体、カメラ、SIGMET・NOWCAST・夜間表示 |
| `src/ui/` | 便一覧や操作パネル |
| `src/styles/` | PC・スマートフォンの画面デザイン |
| `server/` | 外部API取得、キャッシュ、AI解説、音声生成 |
| `public/models/` | 航空機のGLB形式3Dモデル |
| `tests/` | 自動テスト |
| `cloudbuild.yaml`・`Dockerfile` | Google Cloudへのビルド・デプロイ設定 |

主な技術はTypeScript、Vite、Node.js、Google Maps JavaScript APIの `maps3d`、Gemini、Google Cloud Text-to-Speechです。

### Cloud Runへの配置

`cloudbuild.yaml` は、Dockerイメージを作成してArtifact Registryへ保存し、Cloud Runの `skyroute` サービスへ配置する構成です。リージョンは `asia-northeast1` です。GitHubからの自動実行には、別途Cloud Buildトリガーの設定が必要です。

Google MapsとAeroAPIのキーは設定ファイルに記載されたSecret Managerのシークレットを使用します。AI解説には実行環境の `GEMINI_API_KEY`、音声にはText-to-Speech APIの有効化と実行サービスアカウントの適切な権限が必要です。

## 利用上の注意・データの扱い

SkyRouteは、飛行状況と気象を分かりやすく見るためのアプリです。実際の航空運航や安全判断のためのシステムではありません。

位置・時刻・経路・気象には、更新遅延、欠損、推定値、取得失敗、画像タイルから読み取る値の誤差などが含まれます。再生中の機体位置や気象の立体表示も、現実を完全に再現するものではありません。

地図、外部データ、API、航空機モデルの利用は、それぞれに適用される利用条件に従ってください。
